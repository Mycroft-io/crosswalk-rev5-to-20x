Crosswalk 20x

Reads a FedRAMP certification package and lays it against the Rev5 control baseline, so an agency reviewer can see what the provider covers and what is left to decide.

    You are looking at FedRAMP's fictional sample package (Meridian Federal Systems), which reports only 15 of 46 indicators. Open your own files, or drop them anywhere on this page, to replace it. Files are read in this browser tab and are not uploaded.

    These files point to different Certification Package Overviews, so they may describe different services. Check that they belong together.

    A link between an indicator and a control is one FedRAMP publishes as "related". It shows a reviewer where to look. It does not show the control is satisfied, and this view is not a System Security Plan.

    Built on FedRAMP's public-domain data: Consolidated Rules for 2026 version (indicator and rule mappings, Rev5 baselines), the CR26 JSON schemas, NIST SP 800-53 Rev. 5 control titles, and FedRAMP's agency control guidance.

    Not a FedRAMP tool and not endorsed by FedRAMP. The page makes no network requests.
