Read a FedRAMP 20x package control by control

Crosswalk 20x lays a certification package against the Rev5 baseline, so an agency reviewer can see what the provider covers and what is left to decide. Files stay in your browser.

Upload a certification package

Drop the JSON files from a FedRAMP 20x package here, or choose them. Any of the six file types works on its own; the more you add, the more complete the view.

  • Certification Package Overview
  • Security Decision Record
  • Ongoing Certification Report
  • Vulnerability Detail Report
  • Accepted Vulnerability Info
  • Historical Vulnerability Activity

Files are read in this browser tab, checked against FedRAMP's schemas, and never uploaded anywhere.

    You are looking at FedRAMP's fictional sample package (Meridian Federal Systems), which reports only 15 of 46 indicators. Upload your own files, or drop them anywhere on this page, to replace it.

    These files point to different Certification Package Overviews, so they may describe different services. Check that they belong together.

    Coverage of the Rev5 baseline

    A link between an indicator and a control is one FedRAMP publishes as "related". It shows a reviewer where to look. It does not show the control is satisfied, and this view is not a System Security Plan.

    Built and maintained by Mycroft and released as open source under Apache-2.0 on GitHub. Not a FedRAMP tool and not endorsed by FedRAMP. The page makes no network requests.

    Built on FedRAMP's public-domain data: Consolidated Rules for 2026 version (indicator and rule mappings, Rev5 baselines), the CR26 JSON schemas, NIST SP 800-53 Rev. 5 control titles, and FedRAMP's agency control guidance.
